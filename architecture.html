verifAI · system architecture

The skill ledger is the single source of truth. Every assistant request passes the AI gate, which only lets the model use concepts the ledger says you've proven. Each user brings their own provider key and picks the model.

How the gate decides
1. Every concept the request needs is verified: the model may write the code.
2. Some aren't: it explains them and links the lesson, or offers a guided task.
3. In a guided task: it teaches and reviews, the learner writes.
